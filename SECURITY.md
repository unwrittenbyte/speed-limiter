# Security reporting

Please report suspected vulnerabilities privately using GitHub's private vulnerability reporting feature.

Include the version, operating system, reproduction steps and potential impact. Do not include passwords, proxy credentials, browsing histories or other sensitive information.

Reports are reviewed on a best-effort basis. No response time, security updates or ongoing maintenance are guaranteed.

The local proxy is not a VPN, firewall or security enforcement boundary. Keep any required VPN protection active. The optional VPN compatibility setting relaxes narrowly scoped reserved-address checks and is off by default.
