Set up your speed limiter

A free Windows companion is required. The Chrome extension alone cannot throttle browser-wide traffic.

  1. Download the matching companion installer from the developer's official download page linked in the Chrome Web Store listing.
  2. Close Chrome fully and run the installer. It installs for your Windows account only; Python is not required.
  3. Reopen Chrome, open the extension, and select Check Windows companion.
  4. Read and accept the local traffic disclosure, choose a speed and turn limiting on.

Before using

Windows 10/11, x64 only. The limiter handles HTTP and HTTPS proxy traffic in your regular Chrome profile. It does not throttle other apps, local bypass traffic, incognito, UDP/WebRTC or every Chrome service. Once you connect, switching the limit OFF removes the cap but keeps the local proxy running. Switching ON again should limit ongoing proxied downloads. Connecting or disconnecting the proxy may interrupt connections. Downloads started before connecting can bypass the limiter even after pause/resume; restart those downloads after connecting. If the proxy fails, Chrome can use a direct connection.

Having trouble?

Click Disconnect proxy to restore prior proxy settings. Close other proxy extensions; avoid using this with required corporate proxies or VPNs until compatibility is confirmed. Check your companion version and reinstall if needed. Windows SmartScreen may warn about unsigned or unfamiliar installers. Verify the source of any installer you download.

Optional VPN compatibility (experimental)

If your trusted VPN or DNS filter returns synthetic addresses in 198.18.0.0/15 or the NordVPN Google mapping 192.0.0.88, disconnect the local proxy, reconnect, and tick VPN compatibility mode in the connection dialog. This permits DNS-named web destinations in the benchmarking range and 192.0.0.88 only for google.com and its subdomains, on ports 80/443. Other blocked ranges remain blocked. In this mode Google names prefer an IPv4 OS DNS lookup, with normal DNS fallback if needed. This does not verify VPN ownership of the address and does not change DNS or VPN settings. The popup shows the active compatibility setting near the top. It does not detect whether a VPN is connected. Disable this option by reconnecting with it unchecked when it is no longer needed. Keep required VPN protection active. If browsing fails, disconnect the local proxy and compare.

Uninstall

Click Disconnect proxy, remove the extension, close Chrome and uninstall Speed Limiter Companion from Windows Settings > Apps.
